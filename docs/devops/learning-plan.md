# DevOps Practical Learning Plan

A flexible sequence of exercises to supplement the Windows IAM lab.

| Stage | Topic | Hands-on outcome | Status |
|---|---|---|---|
| 1 | Linux shell | SSH, file permissions, process and service troubleshooting | Planned |
| 2 | Git | Branch, merge, conflict resolution and documentation commits | Planned |
| 3 | Docker | Extend existing Docker Compose foundations | Previously demonstrated |
| 4 | Kubernetes | Deploy and troubleshoot workloads in a sandbox | Planned |
| 5 | CI/CD | Add GitHub Actions validation to a practice project | Planned |
| 6 | Observability | Explore Grafana dashboards and alerts | Planned |
| 7 | Security monitoring | Evaluate lightweight Wazuh/SIEM architecture | Planned |
