# Portfolio Evidence and Screenshot Guide

Screenshots can demonstrate technical results, but all images must be reviewed before committing to this **public** repository.

## Planned examples
- `iam-dc01-domain-health.png` — redacted domain-controller verification.
- `iam-domain-structure.png` — fictional organizational units.
- `iam-security-groups.png` — verified global security groups.
- `iam-fs01-access-tests.png` — **future**, only after authorized/denied results are tested.

## Sanitization checklist
- Crop unrelated browser tabs, email, notifications, personal account names and desktop content.
- Hide passwords, license keys, recovery secrets, tokens and remote access identifiers.
- Avoid posting private home network details not necessary for the learning objective.
- Check screenshots for location/identity data and for unexpected Windows account names.
- Use generic labels if documenting architecture; do not publish full logs from real systems.

Screenshots are optional: short, sanitized command output and test summaries are also acceptable evidence.
